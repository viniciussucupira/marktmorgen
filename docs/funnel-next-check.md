# Suggested next funnel check

The Funnels studio now places a native disclosure on each saved funnel, before
its longer sharing review and step metrics. It selects one manual check from
already-loaded saved configuration and approximate counts. It never changes a
funnel or declares an experiment winner.

Priority is saved launch issue order, unavailable counts, an unreached step,
a product with no completions, the largest fall, then an insufficient sample.
No finding means test the complete customer journey, not a ready-to-sell certificate.
Unavailable product completion data is now reported even when page views loaded;
it is never silently treated as a complete reading or as zero. A page-only step
does not require a product completion metric.

Repair links reuse the existing permission-filtered, selected-store editors,
Forms anchors, payment and billing destinations. Mutation recovery removes them
from keyboard navigation and blocks navigation; settings respect the existing
draft/save guard. No new database, AI, provider request or background work is added.
Prices, allowances, sales gates and fiscal controls are unchanged.

The product direction draws on official ClickFunnels step testing and HighLevel
metric definitions. Their presence does not establish superiority or sales gains:
- https://support.myclickfunnels.com/docs/managing-ab-split-testing-in-funnel-steps/
- https://help.gohighlevel.com/support/solutions/articles/155000005698

Synthetic priority/permissions/escaping/recovery tests and the existing real
browser fixture cover keyboard operation and expanded mobile/desktop accessibility.
