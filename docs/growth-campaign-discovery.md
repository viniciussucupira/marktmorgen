# Growth to campaign discovery
The Growth page now connects list growth, product sales and service enquiry
goals to the corresponding existing campaign catalog. Retention keeps its
buyer/follow-up tools and receives no unrelated acquisition template.
The server derives journey titles, page/form counts and product requirements
through the same starterCard function and real bundles used in Funnels.
Native details work without client state or additional requests. The explicit
link preserves the selected store and goal, disables prefetch and opens the
existing gallery. Setup and publication rules remain unchanged.

Discovery requires the current page permission, has no new store/provider
reads beyond the existing counted studio view, and never calls the campaign
preview/setup endpoint. The target editor keeps its own admission and limits.
No price, plan, visible limit, cost ceiling, tax or payment rule changes.
PLANS_ON_SALE remains false. No forecast, conversion guarantee, consent check,
live stock/delivery check or verified sales uplift is inferred from a template.

Tests cover permission/goal mapping and all four goals at four widths with
keyboard disclosure, selected-store navigation to actual gallery data at390,
no campaign preview requests, no page errors, AA scans and layout fit.
The complete existing CI and synthetic flows are retained. Whole-site AAA,
screen readers and real participants remain work in progress.
