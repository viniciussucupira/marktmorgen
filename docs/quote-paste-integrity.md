# Complete quote pastes

The external-quotation editor refuses a plain-text paste that would exceed the existing quote limit after replacing the selection. It keeps the current words, shows an alert and lets a complete quote within the limit be pasted. UTF-16 lengths and textarea line-ending normalization match the browser's maxlength behavior. This reuses Hazelsong's pure length predicate; no product financial policy or access rule is shared.

The server's existing full-quote validation remains necessary. This guard covers paste events, not every input method or historical clipped quotation. It adds no provider calls, storage, telemetry, entitlement or price changes. Synthetic component checks exercise the actual event handlers with controlled clipboard data; they are not a live-browser verification.
