# Path SVG export accessibility and recovery

The downloaded SVG now associates its full text equivalent through a desc element and aria-describedby, in addition to the short title. The description uses the same validated facts and explicit money choice as the visible card and plain text, so sales/reading time are absent by default. XML escaping is preserved. This improves the artifact semantics; no cross-platform screen-reader certification is claimed.

Blocked Blob/object-URL/download requests are caught, the current card text is selected for manual copying and the status reports that no download could be requested. Allocated object URLs are revoked even if triggering the download throws. Browser acknowledgement still cannot certify that the user saved a file.

Tests cover linked private and opt-in SVG descriptions and an injected object-URL failure at390/1280 within the existing clipboard/privacy/AA/fit tests. Existing actual SVG download assertions retained. No provider/network writes, consent, costs, limits, payment or tax changes.
