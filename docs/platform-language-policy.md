# Current platform language: American English

Owner decision19October2026 (durable queue B1). Marktmorgen's own public pages, studio, Path and platform-to-creator messages currently use American English. The root document declares `en-US`; Open Graph already uses `en_US`. There is no new language selector, request-time translation, browser-language switch or translation provider.

This policy does not rewrite creator-authored pages/products/emails, Portuguese owner quotations in documents, or persisted technical identifiers. Existing creator-store buyer languages are a separate capability in `lib/store-language.ts` and `lib/buyer-words/`; the owner's later checkout item E5 explicitly uses the languages a store already offers. They are not removed or silently remapped by a platform-language declaration. The stored `pt` identifier and existing buyer vocabulary are not changed here. When platform Portuguese is authorized, it will be Brazilian Portuguese, with migration/compatibility assessed explicitly.

Code audit before this change: `app/layout.tsx` used generic `lang="en"` while its social metadata already declared `en_US`. Platform routes inherit this layout. `lib/store-language.ts` explicitly distinguishes English studio labels from creator-chosen buyer languages. `lib/email.ts` is a metered transport for both company and creator mail; forcing creator content through a platform-language transform would change another scope, so no such transform is added. Platform billing and trial notice templates are already English sources; their full spelling/content audit is queue B2, not claimed complete here.
