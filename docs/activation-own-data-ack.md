# Own-data activation acknowledgements

The actual checkout and switch activation functions previously read result[0] before the fixed response shape, then directly read ACK members. A response getter or inherited array element could therefore masquerade as the exact observation. Both entry points now use their existing private observation validator with own length/data descriptors: outer one result, inner two values, own numeric1/2 and safe integer deadline/period end. Oversized cardinalities refuse before numeric member inspection. Accessors, sparse/inherited/symbol responses refuse without invocation. Existing policy/review/binding and clock/deadline/period rules are unchanged.

Tests call both actual activation functions with the existing synthetic funded Redis simulator. They reserve actual simulated source grants (and activate the source for a switch), inject malformed acknowledgements, retain cash/slots/source/pending evidence, prove no getter/member traversal with a positive instrumentation control, then restore normal responses and verify activation and idempotent observation. This does not claim production funding admission or replace the existing real Lua tests. No gates or resource/renewal/restart coverage are enabled.
