# HT13 — Student tutor: cost and source decision before implementation

Decision20October2026: do not implement a new student tutor on the existing base plans at this time. lib/answers-rules.ts and lib/answers.ts answer pre-purchase product-page questions from public page facts and creator notes. They do not load private lesson content or prove a learner’s course access. Their visible included monthly answer requests are Store0, Studio250, Scale400; these and the automatic AI budget already have to support100% existing rights. Relabeling them a student tutor or borrowing their worst-case budget would not preserve those rights.

The existing Store assistant is a separate, closed-sale add-on with700shared replies/month,24,576input bytes,320output tokens, reserved worst cost before each call, code-owned AI label, fact bounds and handoff. Existing course/learner access is separate. No reviewed student-specific retrieval plan binds all private source bytes, reads, cache/retention, purchase revalidation, transcript availability or content rights within the current assistant cost ceiling. A video lesson without an existing authorized transcript must not cause a new caption/transcription operation or an answer from general model knowledge. No new model quote, entitlement, pool, reserve or priced scope is approved here.

A reference lower bound illustrates why a copied allowance is not free:700additional replies/month at the existing assistant’s repository cost of$0.003539 each require$2.4773, conservatively rounded to$2.48/month and$29.76/year before any additional course retrieval or transcript work. This is an economic reference, not a proposed/published tutor allowance or supplier quote for the new use case. No such change was made.
