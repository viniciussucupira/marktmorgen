# Review form answers by opportunity link

Authorized creators can combine text/quiz filters with With linked opportunity or Without linked opportunity. Links use the exact stable form-response reference, not an email match. Other opportunities may share the same contact and are still reviewed in the conversion dialog. Selection CSVs contain exactly the visible answers; all kept answers remain separately downloadable.

The Forms page batches stage configuration and opportunity records in one store-scoped CRM request. Missing, malformed, failed or inconsistent replies produce explicit unavailability, never a confirmed empty CRM. A null stage configuration and an empty hash are confirmed defaults/zero. All stored opportunity identities, source references and contact values used for matching must be readable.

When CRM cannot be checked, opportunity filtering and new conversion are paused. Answer search, quiz filters and exports remain available; source answers and unsaved conversion drafts are preserved. Existing readDeals callers and explicit server conversion permissions are unchanged. No opportunity, message or marketing enrollment is created automatically.

Verification uses synthetic Redis replies, filter behavior and static render checks. No live customer mutation or authenticated interactive browser verification is claimed.

A fully validated conversion acknowledgement updates the local worklist immediately, without another server read. Client facts are scoped to the selected store and filled only for identities absent from refreshed server data. A partial or mismatched acknowledgement cannot mark an answer linked. Drafts and filter state reset on an explicit store change through the keyed editor boundary.
