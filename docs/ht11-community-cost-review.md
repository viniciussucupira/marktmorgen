# HT11 — Creator-stage community: cost decision before operation

Decision20October2026: do not implement or open a Marktmorgen customer community yet. Existing lib/community.ts and /studio/community manage a creator’s own buyer community. Existing Discord rules/access and /studio/discord connect a creator’s own server and map purchased products to roles; they are not a pre-authorized Marktmorgen customer space. Bot permissions explicitly exclude reading/writing messages. No existing role map for Starting/First sales/Growing, verified platform-owned destination or customer-stage access policy was found in the reviewed code.

Reusing that code does not price the new operation. The plan registry already counts a store’s capped buyer actions, service calls, community pictures/records and email. It does not assign this proposed shared platform space a per-paying-client budget for moderation/support/abuse handling, room ownership, role maintenance and retention, notifications and any host/service cost. No reviewed hours/rate/maximum or reserve exists for these new duties. Zero supplier subscription is not proof of zero full cost. Creating a Discord server/channel/role or inviting customers would also be an external operation beyond the synthetic-only boundary; none was attempted.
