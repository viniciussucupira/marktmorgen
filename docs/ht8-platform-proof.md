# HT8 — Quantitative proof without invented numbers
Platform counts are a prepared static reviewed snapshot, not a public-page database scan. No audited platform-wide dataset is available; snapshot is null, so every platform counter and its section remain absent. Unknown is never displayed as zero.
Configured separate floors:100 stores created,1000 settled paid sales,50 creators active in the last30 days. A snapshot must identify live data, exclude demo/test, carry a source evidence reference and exact as-of timestamp, use nonnegative safe integer counts, a30-day activity definition, and be no more than30 days old at review. Below-floor, unknown, fractional, invalid/future/stale or unsupported figures stay hidden. Published numbers are exact localized integers, no upward rounding or plus suffix, with their timestamp. Source evidence stays private.
Data preparation must use existing audited operational exports, deduplicate store/payment/creator identifiers, exclude demos/tests and document definitions (sales means settled paid non-refunded purchases, active means an observed creator action in preceding30 days). A hand-edited marketing estimate is not evidence. Updating the static snapshot needs an evidence review and deployment; no new scheduled query/provider/cost is activated here.

Existing recent-sales audit: source events are settled live-mode store purchases, opt-in only, no buyer identities, bounded seven days/three cards, no looping and cached verification for up tofive minutes. Fixes missing/invalid/future purchase timestamp being treated as now; rejects noninteger amounts/times, malformed/future/old cached records and cached hidden/removed products using the already-loaded catalog. No extra Redis/provider query. Existing refund verification/cache/caps/opt-in/creator/buyer language rules unchanged.
Synthetic tests cover null/below/exact threshold/date/evidence and timestamp/cache/visibility conditions. Browser confirms actual unknown counters absent and no write/viewer fiction. No real payment/account/message/external submission. Full final-head CI required.
