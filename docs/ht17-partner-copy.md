# HT17 — Partner voice in public pages and studio messages

Shared platform microcopy follows an action-first pattern: say what happened, what the person can do next, and any actual condition. Use short American English sentences and familiar words. Keep permission, quota, consent, price, timing and availability qualifications. Do not blame the person, imply an uncertain write succeeded, promise a restoration time, infer why an address disappeared, or promise earnings or commercial results.

Implemented in the existing STUDIO_MESSAGES registry: permission/recovery/access, file and record space, interrupted uploads, hourly allowance and temporary file unavailability. Every existing error key stays the same. Record space is distinguished from file storage; the text asks people to review content before removing it and does not suggest upgrading while sales are closed. The global error boundary gives a retry/navigation action without promising the page will return shortly. The existing404 page asks for an address check without inventing a reason for a missing store. Feature-page and Growth introductions use a clear next step rather than a rhetorical sales pitch. This is a targeted shared-template pass, not a claim that every creator-authored text was rewritten.

Examples: “That is a lot of uploads” becomes “This hour’s upload allowance is used. Try again later.” A denied role asks the person to have the owner review permissions; it does not imply access has changed. An unavailable file receiver asks them to keep their file and retry; it does not claim the upload is stored. Existing form confirmations and API refusal semantics remain intact.

No creator content, email body, sequence, buyer language, translated dictionary, persisted error identifier, plan price, visible allowance, opt-in, permission or tax/commercial gate changes. No AI/provider call, account, payment, external message/submission, background operation or variable supplier cost. PLANS_ON_SALE=false and COMMISSION_LIVE=false; the60% minimum net margin in the worst month after all Brazil/US taxes remains binding and is not certified by copy edits.
