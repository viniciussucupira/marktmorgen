# Copyable Path card text

The share card has a read-only, labeled text equivalent generated from the same validated facts and explicit money opt-in as its preview and SVG. The amount and reading time are absent by default. Nothing is copied, posted or sent automatically. A successful clipboard acknowledgement is announced; a denied or unavailable clipboard selects the text for manual copying. A synchronous lock prevents duplicate pending copies; the money choice is held until the current snapshot copy resolves. Changing it clears prior success wording.

Download wording describes a browser request, not proof a file was saved. Server data, consent wording, costs, limits, financial/tax rules and gates do not change.

Unit checks cover private default/explicit money/reading/unknown/invalid text. Synthetic browser checks at390/1280 use local clipboard stand-ins for keyboard copy, pending duplicate prevention and denied-copy selection; scoped AA and fit checked. Existing SVG download and privacy tests retained. No claim of whole-site AAA or human assistive-technology validation.
